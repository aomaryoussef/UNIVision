How GPA is Calculated
GPA = Sum(Grade Points x Credits) / Total Credits. Each letter grade has a point value: A+ = 4.0, A = 4.0, A- = 3.7, B+ = 3.3, B = 3.0, B- = 2.7, C+ = 2.3, C = 2.0, C- = 1.7, D+ = 1.3, D = 1.0, D- = 0.7, F = 0.0. Use this simulator to find out what grades you need to reach your target GPA.
